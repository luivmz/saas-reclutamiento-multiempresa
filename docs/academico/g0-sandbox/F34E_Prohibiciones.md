# F34E — Prohibiciones absolutas

> Fase F34E, versión 1 (04/10/2026). Rigen **aunque G0-SBX esté APROBADA CON RESTRICCIONES**. Cualquier incumplimiento revoca G0-SBX.

| Prohibido | Motivo |
|---|---|
| Datos reales de cualquier tipo | Contrato 7; regla de datos de ADR-005 §6.10 |
| Nombres reales de candidatos | Ídem |
| CV o documentos reales | Ídem |
| DNI, correo o teléfono reales | Ídem |
| Audios o vídeos reales | ADR-005 §6.7; CAP-27 |
| Biometría | ADR-005 §6.7 |
| Inferencia de emoción, personalidad, honestidad, estrés o inteligencia | ADR-005 §6.7; DS 115-2025-PCM (lectura F30) |
| Scoring ML de candidatos | Contrato 4; ADR-001 |
| Recomendación de candidatos | ADR-001; OUT-04 |
| Identificar un «mejor candidato» | ADR-001; F33 |
| Ranking automático nuevo | RF-21 vigente no se reemplaza |
| Decisión final automática | RF-23 humana; ADR-002 |
| Alcance C | Exige G0 real APROBADA y un ADR adicional |
| Despliegue productivo | G0 real NO APROBADA |
| Integración con datos reales | Regla de datos; G0-02, G0-03 y G0-12 pendientes |

Ningún resultado de F35-SBX puede alimentar el runtime, las bases de datos productivas, el servicio ML de RF-29 ni ninguna decisión sobre personas reales.
