## Lectura y accesibilidad

Fondo claro, tipografía Arial (cuerpo 18–22 px; pies/conectores 16 px, equivalente nominal mínimo a 12 pt al tamaño original), contraste oscuro y conectores ortogonales. No reducir la escala de exportación en Word/PPT por debajo de la lectura cómoda. Las etiquetas `[H]`, `[IA]`, `[SIS]`, `[DAT]`, `[QA]`, `[DOC]`, `[PROC]`, las formas y la posición complementan el color. Las categorías colaborativas se indican en texto. El SVG tiene título/descripción; el Markdown ofrece alternativa textual. No se afirma certificación de accesibilidad.

## Advertencias comunes

- AS-IS preliminar y pendiente de validación institucional; TO-BE y agrupación de procesos propuestos.
- AI-DLC es marco de contraste; no adopción formal demostrada.
- Sonar es histórico; Gate OK con Small Changes y New Code 50 %, no 80 %. Sin LCOV frontend importado.
- Metadatos de 20 artículos validados previamente; contenido científico y efecto causal local tienen las limitaciones del catálogo.
- No se alteraron evidencias V1/V2 ni software.
